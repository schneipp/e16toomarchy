# Animated showcase

The README's looping feature reel highlights gallery browsing, cached previews, original bitmap frames, focused/unfocused states and the native topbar workflow.

| Asset | Format |
| --- | --- |
| [Animated README demo](assets/e16toomarchy-demo.gif) | Approximately 14 seconds, 1040 × 650, seamless loop |
| [Shareable video](assets/e16toomarchy-demo.mp4) | H.264, 1200 × 750, fast-start MP4 |
| [Static poster](assets/e16toomarchy-demo-poster.png) | 1200 × 750 PNG |

This is a designed, rendered feature showcase, rather than a live screen recording. Gallery cards use original E16 screenshots. Window decorations are generated by this project's actual `e16-frame-preview` renderer, with an illustrated terminal client inside them. No personal desktop content is included.

## Reproduce

Requires the project's Python dependencies, native renderer build dependencies, `ffmpeg`, and `fontconfig`. The authored typography uses Liberation Sans and JetBrains Mono, with fontconfig fallback when unavailable.

```sh
make preview
.venv/bin/python tools/create_marketing_demo.py
```

The generator uses existing converted BrushedMetal, Aqua and AlienConsole themes when present in `converted/`, or downloads and converts those three themes into a temporary work directory. Gallery artwork comes from the normal local picker cache, with downloads only for missing images. To use another existing gallery cache:

```sh
.venv/bin/python tools/create_marketing_demo.py --gallery-cache /path/to/cache/e16toomarchy
```

`--output` changes the artifact destination; `--fps` sets the render rate between 8 and 30. Temporary full-resolution frames are deleted after encoding. A local `demo-contact-sheet.png` is produced for review and is not needed by the README.
